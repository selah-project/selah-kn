# ಹೀಬ್ರೂ ಬೈಬಲ್ — ಕನ್ನಡ ಅನುವಾದ

ಹೀಬ್ರೂ ಬೈಬಲ್ (ತನಾಖ್)ನ ವಚನ-ವಚನ ಅನುವಾದ — ಮೂಲ ಅಕ್ಷರಗಳಿಗೆ
ನಿಷ್ಠವಾದದ್ದು.

## ಮೊದಲು ಹೀಬ್ರೂ

ಈ ಅನುವಾದ ನಿಮ್ಮನ್ನು ಹೀಬ್ರೂವಿನವರೆಗೆ ಕರೆದೊಯ್ಯುವುದಕ್ಕಾಗಿ — ಅದರ
ಜಾಗವನ್ನು ಆಕ್ರಮಿಸುವುದಕ್ಕಲ್ಲ. ಓದಲ್ಪಡುವುದು ಯಾವಾಗಲೂ ಹೀಬ್ರೂವೇ —
ಅದರ ವ್ಯಂಜನಗಳು, ಸ್ವರಗಳು ಮತ್ತು ಚಿಹ್ನೆಗಳು. ಕೆಳಗಿನ ಕನ್ನಡ ಒಂದು
ಕಿಟಕಿ, ಬದಲಿಯಲ್ಲ. ಎರಡೂ ಬೇರೆಯಾದಲ್ಲಿ, ಹೀಬ್ರೂವೇ ಸರಿ.

## ಹೆಸರು

ನಾಲ್ಕು-ಅಕ್ಷರದ ಹೆಸರು ಬರುವಲ್ಲೆಲ್ಲಾ ನಾವು **ಯಾಹ್ವೆ** ಎಂದು
ಬರೆಯುತ್ತೇವೆ — ಅದರ ಜಾಗದಲ್ಲಿ ಯಾವ ಬಿರುದೂ ಇಲ್ಲ, ಯಾವ ಸಾಮಾನ್ಯ
ಪದವೂ ಇಲ್ಲ. ನಾವು **ಯೆಹೋವ** (ಸಂಕರ ರೂಪ) ಬರೆಯುವುದಿಲ್ಲ,
**ಕರ್ತನು** (ಬಿರುದು — ಹೆಸರಲ್ಲ) ಬರೆಯುವುದಿಲ್ಲ, ಮತ್ತು ಹೆಸರಿನ
ಜಾಗದಲ್ಲಿ **ದೇವರು** ಇಡುವುದಿಲ್ಲ. ಹೆಸರು ಇದ್ದಂತೆಯೇ ನಿಲ್ಲುತ್ತದೆ,
ಎಲ್ಲೆಡೆ — ಹೆಸರು ಎಲ್ಲಿದೆ ಎಂದು ಯಾವಾಗಲೂ ಕಾಣುವಂತೆ.

## ಆಲೆಫ್-ತಾವ್ — ⟨את⟩

ಕನ್ನಡ ವಾಕ್ಯಗಳಲ್ಲಿ ನೀವು **⟨את⟩** ಉಳಿಸಲ್ಪಟ್ಟಿರುವುದನ್ನು ಕಾಣುವಿರಿ.
ಹೀಬ್ರೂವಿನಲ್ಲಿ אֵת ಎಂಬುದು ಕರ್ಮದ ಕಡೆಗೆ ಬೆರಳು ತೋರಿಸುವ ಚಿಕ್ಕ ಪದ.
ಕನ್ನಡದಲ್ಲಿ ಅದಕ್ಕೆ ಸಮಾನ ಪದವಿಲ್ಲ, ಮತ್ತು ಹೆಚ್ಚಿನ ಅನುವಾದಗಳು ಅದನ್ನು
ಸದ್ದಿಲ್ಲದೆ ತೆಗೆದುಹಾಕುತ್ತವೆ. ನಾವು ಅದನ್ನು ಆವರಣದಲ್ಲಿ ಕಾಣುವಂತೆ
ಇಡುತ್ತೇವೆ — ಏಕೆಂದರೆ ಅದು ಭಾಷೆಯ ರಚನೆಯ ಭಾಗ. ಅಳಿಸುವ ಬದಲು,
ಅದರ ಇರುವಿಕೆಯನ್ನು ತೋರಿಸುವುದನ್ನೇ ನಾವು ಆರಿಸುತ್ತೇವೆ.

## ⟨ಆವರಣ⟩ದೊಳಗಿನ ಪದಗಳು

⟨ಇಂತಹ⟩ ಆವರಣಗಳು **ಹೀಬ್ರೂವಿನಲ್ಲಿ ಇಲ್ಲದ** ಪದಗಳನ್ನು
ಗುರುತಿಸುತ್ತವೆ — ಕನ್ನಡ ವಾಕ್ಯ ನಿಲ್ಲಲು ಬೇಕಾದ ಸೇರ್ಪಡೆಗಳು.
ಗುರುತಿಲ್ಲದೆ ಬೆರೆಸುವ ಬದಲು ನಾವು ಅವನ್ನು ಆವರಣದಲ್ಲಿ ಇಡುತ್ತೇವೆ —
ಮೂಲ ಹೀಬ್ರೂ ಪದಗಳು ಮತ್ತು ಕನ್ನಡದ ಅಗತ್ಯಕ್ಕಾಗಿ ಸೇರಿದ ಪದಗಳು
ಯಾವಾಗಲೂ ಬೇರೆಬೇರೆಯಾಗಿ ಗುರುತಿಸಲ್ಪಡುವಂತೆ.

## ಹೆಸರುಗಳು ಮತ್ತು ಬಿರುದುಗಳು

ಪವಿತ್ರನನ್ನು ಸೂಚಿಸುವ ಹೀಬ್ರೂ ಪದಗಳು — **ಎಲೋಹೀಂ**, **ಎಲ್**,
**ಶದ್ದಾಯ್**, **ಅದೋನಾಯ್**, **ಯಾಹ್** — ಅವುಗಳ ಉಚ್ಚಾರಣೆಯಂತೆ
ಬರೆಯಲ್ಪಡುತ್ತವೆ. ಎಲ್ಲವನ್ನೂ ಒಂದೇ ಪದಕ್ಕೆ ಒತ್ತಲಾಗುವುದಿಲ್ಲ; ಪ್ರತಿಯೊಂದೂ
ತನ್ನದೇ ಭಾರವನ್ನು ಹೊರುತ್ತದೆ. ವ್ಯಕ್ತಿ-ಸ್ಥಳಗಳ ಹೆಸರುಗಳೂ ಹೀಬ್ರೂ ರೂಪವನ್ನು
ಅನುಸರಿಸುತ್ತವೆ: ಅವ್ರಾಹಾಂ, ಯಿತ್ಸಾಕ್, ಯಾಕೋವ್, ಮೋಶೆ, ಯೆರೂಶಾಲಾಯಿಂ.

## ಗುರುತು ಮಾಡಿದ ಪದಗಳು

- **ಹೆಸೆದ್** (חֶסֶד) — ಒಡಂಬಡಿಕೆಯ ನಿಷ್ಠಾವಂತ ಪ್ರೀತಿ. ಕೇವಲ "ದಯೆ"
  ಅಲ್ಲ, ಕೇವಲ "ಪ್ರೀತಿ" ಅಲ್ಲ. ಯಾವ ಒಂದು ಕನ್ನಡ ಪದವೂ ಅದನ್ನು ಪೂರ್ಣ
  ಹೊರಲಾರದು.
- **ಶೆಓಲ್** (שְׁאוֹל) — ಸತ್ತವರ ಸ್ಥಳ, ಹೀಬ್ರೂ ಹೇಳುವಂತೆ. "ನರಕ" ಅಲ್ಲ.
- **ನೆಫೆಶ್**, **ರೂಅಖ್**, **ಕಾವೋದ್** — ಸಂದರ್ಭಾನುಸಾರ (ಜೀವ ಅಥವಾ
  ಜೀವನ, ಆತ್ಮ ಅಥವಾ ಗಾಳಿ, ಮಹಿಮೆ ಅಥವಾ ಭಾರ) — ಒಂದೇ ಪದಕ್ಕೆ
  ಮೊಳೆ ಹೊಡೆಯಲಾಗುವುದಿಲ್ಲ.

## ಪ್ರತಿ ವಚನ ತನ್ನದೇ ಬೆಳಕಿನಲ್ಲಿ

ಪ್ರತಿ ವಚನದ ಅನುವಾದ ಅದು ತನ್ನ ಜಾಗದಲ್ಲಿ ಹೇಳುವುದರಂತೆಯೇ ಆಗುತ್ತದೆ —
ಎಲೋಹೀಂ ಒಬ್ಬನೇ ಎಂಬ ಹೀಬ್ರೂ ಶ್ರದ್ಧೆಯಲ್ಲಿ ಓದಲ್ಪಡುತ್ತದೆ. ನಂತರ ಬಂದ
ಸಿದ್ಧಾಂತಗಳು ಸೇರಿಸಲ್ಪಡುವುದಿಲ್ಲ; ಕಥೆಯ ಅಂತ್ಯವನ್ನು ಅದರ ಆರಂಭದಲ್ಲಿ
ಓದಲಾಗುವುದಿಲ್ಲ. ಪದಗಳು ತಮ್ಮ ಜಾಗದಲ್ಲಿ ಹೊರುವ ಅರ್ಥವನ್ನು ಹರಿಯಲು
ಬಿಡುವುದೇ — ಉದ್ದೇಶ.

## ಕಡತಗಳ ರಚನೆ

ಒಂದು ವಚನ, ಒಂದು ಕಡತ: ವಚನವು ಸ್ವತಃ, ಮತ್ತು ಪ್ರತಿ ಪದದ ಅರ್ಥ
ಹೀಬ್ರೂವಿನ ಪಕ್ಕದಲ್ಲಿ — ಪ್ರತಿ ಹೀಬ್ರೂ ಪದವನ್ನು ಅದರ ಕನ್ನಡ ಪದದ
ಎದುರು ಓದಬಹುದಾದಂತೆ.
